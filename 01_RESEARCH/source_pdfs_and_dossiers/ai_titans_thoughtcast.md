* **Стенфорд та Loopt:** Вступив у 2003 р. на комп'ютерні науки, у 2005 р. кинув навчання заради стартапу Loopt (перший набір Y Combinator S05). Продав компанію у 2012 р. корпорації Green Dot за $43.4 млн.
* **Y Combinator та OpenAI:** У 2014 р. Пол Грем призначив його президентом Y Combinator. У грудні 2015 р. разом з Ілоном Маском та іншими заснував OpenAI. У 2019 р. очолив OpenAI як повноцінний CEO, провів реструктуризацію у capped-profit і залучив $1 млрд від Microsoft.
* **Криза листопада 2023:** 17 листопада був раптово звільнений радою директорів. Після ультиматуму 730+ із 770 співробітників за 5 днів тріумфально повернувся на посаду CEO з переформатованою радою.

### 2. Дженсен Хуанг
* **Походження:** 17 лютого 1963 р., Тайнань (Тайвань). У 1972 р. (у 9 років) відправлений до США в баптистський інтернат Oneida Baptist Institute (Кентуккі), де чистив громадські туалети та навчав сусіда по кімнаті грамоти в обмін на захист.

У 2006 р. зробив ставку на CUDA, понад 10 років утримуючи платформу попри тиск Уолл-стріт. Довів капіталізацію компанії до >$3 трлн.

# ЧАСТИНА 3. АРХІТЕКТУРА МЕДІА-ПРОЕКТУ ТА ПАЙПЛАЙН

### 1. Формат «Cinematic Thoughtcast»
* **Хронометраж:** 18–25 хвилин.
* **Жанр:** Інтелектуальний документальний відеоесей із високою щільністю смислу.
* **Візуальний стиль:** Відмова від згенерованих фальшивих цифрових облич; фокус на матеріальній культурі (архітектура процесорів, векторні простори, макро-симуляції фізики, автентичні архівні кадри).
* **Звуковий код:** Downtempo / Ambient Trip-Hop на темпі **92 BPM** з індустріальною точністю саунд-дизайну та сайдчейном.

### 2. Студія одного шоуранера (7 цехів)
1. **Google NotebookLM:** Закритий дослідницький інститут. Валідація першоджерел, пошук неочевидних паралелей, генерація англомовного Audio Overview для пошуку драматургічної осі.
2. **Gemini:** Співсценарист і режисер. Перетворення фактів на художній текст зі швидкістю читання 115–120 слів/хв та режисерською розміткою `[SFX]`, `[PAUSE]`.
3. **Google AI Studio:** Інженерна лабораторія. Фіксація System Prompts, калібрування температури (0.4–0.6), пакетна генерація таблиць розкадровки для відеогенератора.
4. **Google AntiGravity:** Командний пункт розробника. Розгортання дерева папок, запуск Git-синхронізації, створення інтерактивного дашборду, бекапи в Google Drive.
5. **Suno Pro:** Приватний оркестр. Генерація 3 модульних інструментальних тем на 92 BPM (*Introspection*, *Tension*, *Triumph*) з комерційною ліцензією.
6. **Google Flow / Google Veo:** Цех комп'ютерної графіки. Рендер 4K 24fps 3D-симуляцій за формулою: `[Камера] + [Об'єкт] + [Матеріал] + [Освітлення Octane] + [35mm grain]`.
7. **DaVinci Resolve Studio:** Фінальний хаб збірки. Монтажна сітка 92 BPM на Edit Page, сайдчейн-компресія (-3dB Ducking) на Fairlight, плівковий лук Kodak 2383 на Color Page, швейцарська типографіка на Fusion.

```bash
#!/usr/bin/env bash
set -e
REPO_NAME="ai-titans-thoughtcast"
GITHUB_USER="tfm-shell"

if [ ! -d ".git" ]; then
    git init
    git branch -M main
fi

git add README.md .gitignore 07_DASHBOARD/ index.html 08_AUTOMATION/ 01_RESEARCH/ 02_SCRIPTS/ 04_VIDEO_PROMPTS/

        gh repo create "$GITHUB_USER/$REPO_NAME" --public --source=. --remote=origin --push

fi
```

### PHASE 4: GOOGLE DRIVE BACKUP ENGINE
In `08_AUTOMATION/scripts/gdrive_backup.sh`:
```bash
#!/usr/bin/env bash
set -e
BACKUP_DIR="09_BACKUPS"
TIMESTAMP=$(date +'%Y%m%d_%H%M%S')
ARCHIVE_NAME="ai_titans_backup_${TIMESTAMP}.tar.gz"

mkdir -p "$BACKUP_DIR"
tar --exclude='.git' --exclude='03_AUDIO' --exclude='05_RAW_FOOTAGE' --exclude='06_DAVINCI_PROJECTS' --exclude="$BACKUP_DIR" -czf "$BACKUP_DIR/$ARCHIVE_NAME" .

if command -v rclone &> /dev/null && rclone listremotes | grep -q "gdrive:"; then
    rclone copy "$BACKUP_DIR/$ARCHIVE_NAME" gdrive:AI_Titans_Backups/
fi
```
Make executable: `chmod +x 08_AUTOMATION/scripts/gdrive_backup.sh`.

# ЧАСТИНА 6. ІНСТРУКЦІЯ З ОЗВУЧЕННЯ (ELEVENLABS ТА SSML)

### 1. YouTube Multi-Language Audio
Ви завантажуєте один відеофайл на YouTube, а потім у вкладці **Субтитри та аудіо** додаєте окремі аудіодоріжки (Українська за замовчуванням + Англійська). Глядач автоматично отримує потрібний голос.

### 2. Керування ритмом (120 wpm) в ElevenLabs
1. Використовуйте модель **Eleven Multilingual v2**.
2. Встановіть повзунок **Speed** на значення `0.85 – 0.90`, щоб сповільнити диктора до 115–120 слів на хвилину.
3. **Паузи та вдихи:**
   * Вставляйте теги `[sigh]`, `[breath]` для природного вдиху перед ключовими фразами.
   * Розриви думок позначайте трикрапкою `...` (мікропауза 0.4 сек) або довгим тире `—` (зависання тону).
4. **Speech-to-Speech:** Для найскладніших драматичних сцен наговоріть репліку у свій мікрофон із потрібними паузами та подихом, завантажте в режим Speech-to-Speech і застосуйте глибокий голос диктора.

### 3. Google Cloud Text-to-Speech (SSML шаблон)
Якщо використовується Google Cloud TTS (Chirp / Studio voices), обгортайте текст у розмітку:
```xml
<speak>
  <prosody rate="85%" pitch="-1st">
    У вісім років світ більшості людей обмежений правилами школи.
  </prosody>
  <break time="1.2s" />
```
