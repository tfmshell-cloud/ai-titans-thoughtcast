# Аудіо-інженерія та двомовний пайплайн (Multi-Language Audio Pipeline)
**Проєкт:** Cinematic Thoughtcast: AI Titans  
**Стандарт:** YouTube Multi-Language Audio Tracks (UK / EN), 120 слів/хв (WPM), 48 kHz / 24-bit WAV

---

## 1. Архітектура багатомовного релізу на YouTube
YouTube дозволяє завантажувати кілька аудіодоріжок в одне відео (*Multi-Language Audio Tracks*).
- **Основна доріжка (Default):** Українська (UK)
- **Додаткова доріжка:** Англійська (EN)
- **Перевага:** Глядач автоматично чує потрібну мову згідно з налаштуваннями свого інтерфейсу без фрагментації переглядів на різні канали.

---

## 2. Керування темпом (120 слів/хв), диханням та акцентами

### Метод 1: Розмітка SSML (Google Cloud TTS / ElevenLabs)
Використовується для математичного контролю мілісекунд пауз та швидкості мовлення:

```xml
<speak>
  <!-- Зниження темпу під 115-120 слів на хвилину -->
  <prosody rate="85%" pitch="-2st">
    У вісім років світ більшості людей обмежений правилами школи.
  </prosody>

  <!-- Точна пауза для дихання або музичного такту -->
  <break time="1.4s" />

  <prosody rate="80%">
    У 1993 році хлопчик розпаковує свій перший комп'ютер 
    <emphasis level="strong">Macintosh LC II</emphasis>.
  </prosody>

  <break time="800ms" />
</speak>
```

### Метод 2: Драматургічні аудіо-підказки (ElevenLabs Prompting)
- `[sighs]` або `[deep breath]` — вдих / зітхання перед драматичною думкою.
- `...` (трикрапка) — мікропауза 0.3–0.5 с зі спадом тону.
- `—` (довге тире) — коротка пауза з зависанням інтонації для напруги.
- Капіталізація ключових слів — динамічний акцент гучності.

### Метод 3: Режисерський Speech-to-Speech (STS)
1. Режисер наговорює репліки в мікрофон за секундоміром (120 wpm) з точними акцентами для DaVinci монтажу.
2. Файл подається в ElevenLabs STS.
3. Нейромережа переносить точний таймінг, дихання та ритміку на обраний кінематографічний тембр диктора.

## 3. Технологічна матриця інструментів

| Параметр | ElevenLabs (Projects / STS) | Google Cloud TTS (Chirp / Studio) | Google NotebookLM |
| :--- | :--- | :--- | :--- |
| **Українська мова** | Найвища якість, природні наголоси | Висока (Neural2), легкий синтез | Не підтримується (тільки EN) |
| **Англійська мова** | Рівень голлівудського закадру | Відмінна документальна чіткість | Відмінний розмовний подкаст |
| **Темп (120 WPM)** | Повзунок Speed або Speech-to-Speech | Тег `<prosody rate="...">` | Неможливо зафіксувати |
| **Дихання та паузи** | Теги `[breath]`, `...`, ручні спліти | Теги `<break time="..."/>` | Випадково |
| **Експорт стемами** | WAV 24-bit / 48 kHz | WAV / MP3 | Тільки монолітний файл |

---

## 4. Виробничий цикл (Step-by-Step)
1. **Майстер UK (48 kHz / 24-bit):** Генерація українського треку, зведення в DaVinci Resolve під відеоряд.
2. **Дубляж EN:** Синхронізація перекладеного тексту під тривалість фраз, генерація тим самим голосом (Voice Clone).
3. **YouTube Release:** Додавання доріжок у менеджері субтитрів/аудіо.
